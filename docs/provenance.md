# Provenance

This repository adapts the bounded workflow, safe installer, candidate fingerprint, resilient task ledger, and local-evaluation ideas developed in `metapak/codex-bounded-orchestrator` and `metapak/claude-bounded-orchestrator`, themselves inspired by bounded multi-agent orchestration patterns. Adaptation for OpenCode V2 was performed as an independent community project.
