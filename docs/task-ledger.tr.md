# Şema-2 görev kaydı

Yerel görev kaydı kısa görev kimliği, başlık, bağımlılık, sorumlu rol, durum, deneme, zaman ve geri dönüş bilgisini tutar. `interrupted`, `waiting_user` ve `needs_repair` durumlarını destekler. İstem, konuşma, kaynak kod, günlük ve gizli bilgi saklamaz. Çalışma JSON dosyaları Git tarafından yok sayılır.

Komutlar için `python3 .opencode/tools/ledger.py --help` çalıştırılabilir. Tamamlanmamış zorunlu görev veya eski zorunlu değerlendirme son incelemeyi engeller.
